# V-JEPA2 components

This directory contains only the predictor, vision transformer and supporting modules needed by the cached-feature ThinkJEPA training and evaluation path. It is not a full V-JEPA2 distribution.

Original project: [facebookresearch/vjepa2](https://github.com/facebookresearch/vjepa2).

Retained source files preserve their original copyright headers. See [LICENSE](LICENSE) and [APACHE-LICENSE](APACHE-LICENSE). Full pretraining, feature extraction and unrelated downstream applications are maintained upstream.
